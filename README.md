# 미니 FM (이적시장 시뮬레이터)

가상 선수 100명이 있는 이적시장에서 예산 안에 영입·판매하고, 시즌 1회를 시뮬레이션해 점수를 받는 브라우저 게임입니다.
서버 없이 브라우저에서만 동작하며, 진행 상황은 브라우저(localStorage)에 저장됩니다.

> 비공식 팬 게임이며 어떤 구단·선수와도 관련 없음. 모든 선수 이름과 능력치는 무작위로 생성한 가상 데이터입니다.

## 게임 방법

0. **스태프 고용** (새 게임에서 한 번) — 예산 100억, 무작위 18명으로 시작합니다. 감독(전술가·육성가·협상가·무난한 감독)과
   스카우터(신입·베테랑·정예)를 고용합니다. 계약금은 예산에서 빠집니다. 좋은 스카우터일수록 잠재력 추정이 정확합니다.
1. **이적 기간** — 이적시장에서 영입하고 내 스쿼드에서 판매(가치의 90%)합니다.
   스쿼드는 최대 25명이고, 주급 합계가 상한(5,000만)을 넘는 영입은 할 수 없습니다.
   다 됐으면 **이적시장 종료** → 전력 변화·순지출·유망주 영입으로 매긴 평가 등급(S~F)과 언론·팬 반응이 나옵니다.
2. **시즌** — 10팀이 홈·원정으로 18경기를 치릅니다. 팀 전력은 포지션별 상위 선수(GK 1, DF 4, MF 3, FW 3)의
   능력치 × 컨디션 평균입니다. 강팀도 질 수 있고, 시즌 중 부상자는 전력에서 빠집니다.
3. **결과** — 시즌 점수 = 순위 점수(1위 100 ~ 10위 0) + 재정 점수(예산 증감, 1억 = 1점) + 선수 가치 증감(1억 = 1점).
4. **다음 시즌** — 모든 선수 나이 +1. 23세 이하는 잠재력 쪽으로 성장하고, 31세 이상은 하락합니다.

잠재력은 정확한 값 대신 등급(S/A/B/C)과 스카우트 추정 범위로만 보입니다.

## 실행

```bash
npm install
npm run dev          # 개발 서버
npm run build        # dist/ 에 정적 파일 생성 → 아무 정적 호스팅에 업로드
npm run gen:players  # 선수 데이터 다시 생성 (data/players.json, data/names.json)
```

`SEED=123 npm run gen:players`처럼 시드를 바꾸면 다른 선수단이 만들어집니다. 시드가 같으면 항상 같은 선수단이 나옵니다.

## 이름 패치 파일

선수 이름은 같은 형식의 JSON 파일을 업로드해서 바꿀 수 있습니다. **이름만** 바뀌고 능력치, 나이, 몸값 등은 그대로입니다.

### 형식

```json
[
  { "id": "p001", "name": "새 이름" },
  { "id": "p002", "name": "다른 이름" }
]
```

| 필드 | 타입 | 규칙 |
|---|---|---|
| `id` | 문자열 | 기존 선수 id (`p001` ~ `p100`) |
| `name` | 문자열 | 비어 있으면 안 됨, 앞뒤 공백 제거 후 30자 이하 |

- 파일 최상위는 배열이어야 합니다.
- 100명을 다 적을 필요는 없습니다. 파일에 있는 id만 바뀝니다.
- 존재하지 않는 id나 규칙에 맞지 않는 항목은 건너뛰고, 나머지는 적용됩니다.
- 기본 이름 목록은 [`data/names.json`](data/names.json)에 있습니다. 이 파일을 복사해서 수정하는 게 가장 쉽습니다.

## 선수 데이터

[`data/players.json`](data/players.json) — 선수 1명의 형식:

```json
{
  "id": "p001",
  "name": "정준서",
  "age": 24,
  "position": "GK",
  "ability": 76,
  "potential": 85,
  "value": 431000,
  "wage": 370,
  "form": 1.03,
  "injured": false
}
```

| 필드 | 설명 |
|---|---|
| `position` | `GK` / `DF` / `MF` / `FW` (10 / 35 / 30 / 25명) |
| `age` | 17~38, 평균 25 정규분포 |
| `ability` | 현재 능력 40~95, 평균 62 · 표준편차 9 |
| `potential` | 성장 한계 (ability 이상, 최대 99). 17세는 +0~25, 30세 이상은 +0~2. **게임 화면에는 등급(S/A/B/C) 또는 범위로만 표시** |
| `value` | 몸값, 만 단위 (`10000` = 1억). ability가 높을수록 지수적으로 오르고, 어린 선수는 잠재력 일부가 반영되며, 28세 이후 1년마다 15%씩 감가 |
| `wage` | 주급, 만 단위. 현재 ability 기준 |
| `form` | 컨디션 0.9~1.1 |
| `injured` | 부상 여부 |

선수 이름은 모두 국가별 이름·성 목록을 무작위로 조합한 가상 이름입니다.
